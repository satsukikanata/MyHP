# 音ノ彼方 / 彩月かなた — Official Website

## 概要

「音ノ彼方 / 彩月かなた」の活動情報をまとめた個人ホームページ。

サイト全体を**幻想的な夜の森**としてデザインし、訪問者が森の中へ入り込んでいくような体験を目指す。

単なる情報掲載サイトではなく、

> **「夜の森を訪れ、そこに浮かぶ光を辿りながら、音ノ彼方 / 彩月かなたの活動を知っていく」**

という体験をサイトそのものに持たせる。

PC・スマートフォンのどちらでも、世界観と使いやすさを両立する。

---

# デザインコンセプト

## 世界観

### 幻想的な夜の森

深い夜の森。

木々の間には淡い霧が漂い、ところどころに小さな光が浮かんでいる。

その光は「精霊」を表しているが、人間や動物のような決まった形は持たない。

見る人によって精霊の姿が違って見えるような、**曖昧で抽象的な存在**として表現する。

### キーワード

* 夜の森
* 静寂
* 幻想
* 神秘
* 月明かり
* 木漏れ日ならぬ「月漏れ」
* 霧
* 淡い光
* 星
* 精霊
* 浮遊する光
* 音
* 彼方
* 少し寂しく、でも温かい

# 精霊の表現

サイト内に登場する精霊は、人型・動物型などの明確な形を持たせない。

## ビジュアル

基本的には、

**「夜の森に浮かぶ、小さな光の球」**

として表現する。

完全な球体ではなく、以下のような不定形な表現も取り入れる。

* ぼんやりした光
* 光の粒子
* 小さな球状の光
* 尾を引く光
* ゆっくり明滅する光
* ふわふわ漂う光
* 周囲に小さな粒子を伴う光

光の動きにはランダム性を持たせ、機械的な印象を避ける。

# ローディング演出

サイトを開いた瞬間から、世界観に入り込めるようにする。

## 基本演出

```text
┌──────────────────────────┐
│                          │
│       夜の森             │
│   🌲 🌲 🌲 🌲 🌲          │
│                          │
│        ・                 │
│             ✦            │
│   ・                      │
│                          │
└──────────────────────────┘
              ↓
       木々が左右へ開く
              ↓
┌──────────────────────────┐
│                          │
│       HOME               │
│                          │
│   音ノ彼方 / 彩月かなた    │
│                          │
│        ✦                 │
│   ・          ・          │
│                          │
└──────────────────────────┘
```

## 演出フロー

1. ページを開く
2. 画面いっぱいに夜の森が表示される
3. 木々の間に淡い光が浮かんでいる
4. 光がゆっくり揺らめく
5. 森の奥から淡い光が差し込む
6. 手前の木々が左右へゆっくりはけていく
7. 森の向こうにHOME画面が現れる
8. HOMEのコンテンツがフェードインする
9. 通常のサイト操作へ移行

### 重要事項

ローディングは「待たされる画面」ではなく、**サイトへの入口そのもの**として扱う。

ただし、ユーザーが毎回長い演出を待たされることは避ける。

目安として、演出は短くテンポよくまとめる。

# 技術構成

## 採用候補

### Next.js

サイト全体のフレームワークとして採用する。

理由：

* ページ構成を管理しやすい
* 静的サイトとして公開しやすい
* 将来的な機能追加に対応しやすい
* TypeScriptとの相性が良い

### TypeScript

保守性を高めるためTypeScriptを使用する。

### CSS

基本的なスタイリングに使用する。

必要に応じてCSS Modulesなどを使用する。

### GSAP

ローディング時の木々のアニメーションなど、複雑なアニメーションに使用する。

特に、

* 木々が左右へはける
* フェード
* 光の動き
* ページ遷移
* タイムライン演出

などに利用する。

### Canvas / CSS Animation

浮遊する光や粒子など、常時動く背景演出に使用する。

必要以上にCanvasへ依存せず、CSSだけで実現できるものはCSSで実装する。

# パフォーマンス

幻想的な演出を多用するため、パフォーマンスには注意する。

特にスマートフォンでの動作を重視する。

## 方針

* 画像を最適化する
* 不要なアニメーションを減らす
* GPU負荷を考慮する
* 大量のDOM要素を生成しない
* Canvasの描画量を制限する
* 必要に応じてモバイル用の演出を簡略化する
* `prefers-reduced-motion` に対応する

「綺麗だけど重いサイト」にならないことを重要視する。

# デザインの最終目標

このサイトを訪れた人に、

**「ホームページを見ている」**

というより、

**「夜の森に入って、そこに浮かぶ光を辿っている」**

と感じてもらえることを目標とする。

「音ノ彼方」という名前に合わせて、視覚だけではなく、

**静けさ・余白・光・動き**

によって「音の彼方にある世界」を感じられるサイトを目指す。
