# SCHEDULE モック仕様

## 完成の条件

- [ ] 1週間分を日曜日から土曜日まで、7日分の日付順で表示する。
- [ ] 予定がある日は活動種別・時間・タイトルを表示し、予定がない日は「予定なし」、配信を休む日は「配信お休み」と説明文を表示する。
- [ ] PC幅（601px以上）では日付と予定内容を横並びにし、スマホ幅（600px以下）でも日付・予定内容が読みやすく縦に並んで表示される。

## 決めたこと

- 日付と予定は見た目を確認するための仮置きにする。
- 週の期間は見出しにまとめて表示する。
- 「予定なし」と「配信お休み」は別の表示にする。
- 配信休みの日はタイトルや外部リンクを表示せず、「配信お休み」と「この日の配信はお休みです。」を表示する。
- 配信・イベントのリンクはモック内の仮リンクとし、外部サイトへ移動しない。
- 夜の森の雰囲気に合わせた暗い背景、淡い星、控えめな紫色の装飾を使う。
