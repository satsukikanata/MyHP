# FAN ART モック仕様

## 完成の条件

- [ ] PC幅（701px以上）では作品を最大3点横並びに表示し、スマホ幅（700px以下）では作品を最大2列で表示する。
- [ ] 「前へ」「次へ」で表示する作品を切り替えられ、登録作品数に上限を設けず、全作品を順番に見られる。
- [ ] 作品を選ぶと大きく表示され、閉じる操作でギャラリーに戻れる。
- [ ] 作品が0点の場合は、作品がないことを伝える表示になる。

## 決めたこと

- おすすめ作品を、夜の森に浮かぶ光のように見せるギャラリーにする。
- 1画面に表示する作品は最大3点とし、ページ送りで切り替える。
- 作品登録数に上限は設けない。モック内の作品は見た目を確認するための仮データ。
- 作者名は「A」「B」などの仮名、作品画像はCSSの色や図形で表現する。
- PCとスマホで夜の森の雰囲気をそろえ、スマホでも操作しやすいボタンを使う。
- 空の表示は、モック上の切り替え操作で確認できるようにする。
