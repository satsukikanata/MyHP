# 共通部分の実装意図

## やりたいこと

全ページで共通して使う色・フォント・夜の森の背景と、4つのメニュー（HOME / SCHEDULE / PROFILE / FAN ART）を整える。

## なぜ

どのページを開いても同じ夜の森の世界観を感じられ、見たいページへ迷わず移動できるようにする。

## やらないこと

- HOME・SCHEDULE・PROFILE・FAN ARTそれぞれのページの中身は作らない。
- ローディング演出は作らない。
- 光や粒子以外の新しい演出は追加しない。
- 光や粒子は不規則に動かすが、今回の範囲を超える複雑な演出は作らない。
- 新しいライブラリやインストールを追加しない。
- 見た目の見本である `specs/001-home/mock.html` は変更しない。
