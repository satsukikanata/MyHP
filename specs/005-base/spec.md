# 共通部分の実装仕様

## 完成の条件

- [ ] HOME・SCHEDULE・PROFILE・FAN ART の4ページで、`specs/001-home/mock.html` に合わせた夜の森の色・フォント・背景が共通して表示され、光や粒子が不規則に動く。
- [ ] PC幅では4つのメニューが横一列、スマートフォン幅では2列×2行に並び、どのページからも4ページへ移動できる。
- [ ] PCとスマートフォンのブラウザで文字とメニューが読みやすく操作でき、動きを減らす設定が有効な環境では背景の動きが止まる。

## 決めたこと

- 共通の見た目は `specs/001-home/mock.html` を基準にする。
- メニューは PC で横一列、スマートフォンで2列×2行にする。
- 夜の森の背景は、モックの深い紺色・木々のシルエット・月明かり・霧を基準にする。
- 光や粒子は不規則に動かす。ローディング演出は今回作らない。
- メニュー項目は HOME / SCHEDULE / PROFILE / FAN ART の4つだけにする。SNS と HISTORY は独立したメニューにしない。
- ページごとのコンテンツは今回作らない。
- 外部ライブラリや追加インストールは使わない。
