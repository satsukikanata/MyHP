# PROFILE モック作成手順

## 読んだファイル

- README.md
- AGENTS.md
- css/style.css
- js/main.js
- specs/（既存の仕様ファイルなし）

## Step 1: PROFILEモックの見た目を追加

**変える場所**
- specs/001-profile/mock.html — 新しく作る

**すること**
- 現在のサイトの夜の森・夜空・淡い光の雰囲気を参考に、PROFILEの見た目を1つのHTMLにまとめる。
- プロフィール画像、名前画像、紹介文、CONTENTS・TAG・GENDER・AGE・BIRTHDAY・MEMOを配置する。
- PCでは画像と情報を2列、スマホでは1列にする。
- `mock.html` を見本にする。mock.html は変えない。モックの仮の文字・図形は本物にしない。

**確かめる spec**
- 「PC幅（700px以上）では2列、スマホ幅（700px未満）では1列」
- 「指定されたプロフィール項目が表示される」

**確かめ方**
- mock.htmlをブラウザで開く。
- ブラウザ幅を700px以上と700px未満に変え、画像と情報の並びが切り替わることを見る。

## Step 2: PROFILE IMAGEの切り替えを確認

**変える場所**
- specs/001-profile/mock.html — PROFILE IMAGEのHTML・CSS・JavaScript部分

**すること**
- 3つのモック画像を用意する。
- 「←」「→」で前後の画像へ切り替える。
- 現在の画像番号を表示する。

**確かめる spec**
- 「3つのモック画像を順番に切り替えて表示でき、現在の番号も変わる」

**確かめ方**
- 「→」を押して2枚目、3枚目へ切り替わることを見る。
- 「←」を押して前の画像へ戻ることを見る。
- 3枚目の次に「→」、1枚目の前に「←」を押して最初から繰り返すことを見る。
