# PROFILE ページの実装

## やりたいこと
PROFILE ページを実装し、プロフィール情報、3枚の名前画像の切り替え、2枚のプロフィール画像の切り替え、SNS 3件、HISTORY 3件を実際の内容で表示する。

## なぜ
訪れた人が活動内容やプロフィール、SNS、これまでの活動を PROFILE ページで確認できるようにするため。

## やらないこと
- PROFILE 以外のページの実装・変更はしない。
- 名前画像・プロフィール画像の切り替え、SNS、HISTORY 以外の機能は追加しない。
- HISTORY の項目数に上限は設けないが、初期表示は指定された3件とする。
