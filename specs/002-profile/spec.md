# PROFILE ページの実装仕様

## 完成の条件

- [ ] ブラウザの幅を700px以上・700px未満に変えると、プロフィール画像と情報がそれぞれ左右2列・1列に切り替わり、MEMO は情報欄の横幅いっぱいに表示される。名前は3枚の名前画像で表示され、前後の操作で切り替えられる。
- [ ] プロフィール画像を前後の操作で2枚切り替えられ、表示番号が「01 / 02」「02 / 02」と変わる。プロフィール情報には CONTENTS・TAG・GENDER・AGE（12歳）・BIRTHDAY・MEMO が表示され、SNS は指定された3件が PC では3列、スマートフォンでは1列で表示される。
- [ ] HISTORY に指定された3件が日付順に表示され、data/history.js に項目を追加してページを開き直すと、その項目も表示される。項目数に上限はなく、一覧が空の場合は仮の出来事が表示されない。

## 決めたこと

- PC とスマートフォンのレイアウト切り替えは700pxを境目にする。
- MEMO は情報欄の横幅いっぱいに表示する。
- 名前は画像で表示する。
- 名前画像は3枚、プロフィール画像は2枚を切り替える。プロフィール画像の番号は「01 / 02」形式で表示する。
- SNS は3件、HISTORY の初期表示は3件とする。HISTORY はデータを追加すれば上限なく表示する。
- PROFILE の本文（画像・情報・SNS・HISTORY）は、共通のナビゲーションの下に置く。ナビの位置をほかのページとそろえるため。
- モックにある活動名の小見出しと紹介文は、載せる内容が決まっていないので置かない。
- 画像のファイル名は、名前画像が `images/profile/name-1.png`・`name-2.png`・`name-3.png`、プロフィール画像が `images/profile/profile-1.png`・`profile-2.png`（この順に切り替わる）。画像はあとでこの名前で置く。
- 画像が読み込めないときは、枠と番号の表示を残し、枠の中に代替テキストを文字で出す。
- 名前画像の切り替えにも、プロフィール画像と同じ形の番号（「01 / 03」）を出す。
- HISTORY の一覧が空のときは、「まだ出来事はありません。」とだけ表示する。
- HISTORY は data/history.js に書いた順ではなく、日付（「年/月/日」）の古い順に並べて表示する。
