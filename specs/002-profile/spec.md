# PROFILE モック仕様

## 完成の条件

- [ ] PC幅（700px以上）では、プロフィール画像とプロフィール情報が左右2列で表示され、スマホ幅（700px未満）では1列で表示される。
- [ ] PROFILE IMAGEの「←」「→」を押すと、3つのモック画像を順番に切り替えて表示でき、現在の番号も「01 / 03」のように変わる。
- [ ] PROFILEにはACTIVITY・ACTIVITIES・STYLEを表示せず、CONTENTS・TAG・GENDER・AGE・BIRTHDAY・MEMOを表示する。名前の文字は表示せず、名前画像用の枠を表示する。

## 決めたこと

- プロフィール画像は3枚のモック画像を切り替える。
- 名前は画像で表示する想定にする。
- モックの画像は実画像ではなく、CSSの図形で表現する。
- PCとスマホの切り替えは700pxを境目にする。
- MEMOは横幅いっぱいに表示する。
